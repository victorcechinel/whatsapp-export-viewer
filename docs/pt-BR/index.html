Como funciona

Do ZIP do WhatsApp para um site offline

  1. Exporte uma conversa do WhatsApp com mídias incluídas.
  2. Abra o app e selecione o arquivo ZIP.
  3. Escolha a pasta de saída e seu nome na conversa.
  4. Gere o arquivo e abra o index.html.
Automação por CLI
whatsapp-export-viewer "WhatsApp Chat.zip" \
  --output conversa-html \
  --owner "Seu Nome" \
  --locale pt-BR \
  --date-from 01/06/2026 \
  --date-to 30/06/2026

Privacidade

Suas conversas ficam no seu computador

O conversor não envia mensagens, não usa backend e não adiciona scripts de rastreamento ao arquivo gerado.

HTML offline

A pasta gerada abre diretamente no navegador.
