Downloads

Install or run it on your platform

Use the desktop app when you do not want the terminal, or use the command line for automation and batch exports.

Windows

Download the Windows package, extract it, and run the viewer application.

macOS

Download the Apple Silicon or Intel build, extract it, and open the app or CLI.

Linux

Download the Linux archive, make the binary executable if needed, and run it locally.

How it works

From WhatsApp ZIP to offline website

  1. Export a WhatsApp chat with media included.
  2. Open the app and select the ZIP file.
  3. Choose the output folder and your participant name.
  4. Generate the archive and open index.html.
CLI automation
whatsapp-export-viewer "WhatsApp Chat.zip" \
  --output chat-html \
  --owner "Your Name"

Privacy

Your conversations stay on your computer

The converter does not upload your messages, does not use a backend, and does not add tracking scripts to the generated archive.

Offline HTML

The generated folder opens directly in your browser.

Media galleries

Browse images, videos, audio messages, and documents by date and sender.
