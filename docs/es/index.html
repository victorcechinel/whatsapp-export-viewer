Descargas

Instala o ejecútalo en tu plataforma

Usa la app de escritorio si no quieres terminal, o la línea de comandos para automatización y lotes.

Windows

Descarga el paquete de Windows, extráelo y ejecuta la aplicación.

macOS

Descarga la versión Apple Silicon o Intel, extráela y abre la app o CLI.

Linux

Descarga el archivo de Linux, marca el binario como ejecutable si hace falta y ejecútalo localmente.

Cómo funciona

Del ZIP de WhatsApp a un sitio offline

  1. Exporta un chat de WhatsApp con medios incluidos.
  2. Abre la app y selecciona el archivo ZIP.
  3. Elige la carpeta de salida y tu nombre en el chat.
  4. Genera el archivo y abre index.html.
Automatización por CLI
whatsapp-export-viewer "WhatsApp Chat.zip" \
  --output chat-html \
  --owner "Tu Nombre" \
  --convert-audio

Privacidad

Tus conversaciones se quedan en tu computadora

El conversor no sube mensajes, no usa backend y no añade scripts de rastreo al archivo generado.

HTML offline

La carpeta generada abre directamente en tu navegador.
